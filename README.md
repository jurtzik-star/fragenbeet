# Fragenbeet

Klick-Prototyp einer mitwachsenden Frage-Antwort-App für die Einarbeitung neuer Mitarbeiter bei der Landesgartenschau 2028.

Neue Teammitglieder stellen Fragen; ist die Antwort schon bekannt, bekommen sie sie sofort. Ist sie neu, landet die Frage in der Team-Ansicht zur einmaligen Beantwortung — danach steht sie für alle im Beet.

## Nutzung

Diese Datei (`index.html`) ist vollständig eigenständig — kein Build-Schritt nötig. Über GitHub Pages (Settings → Pages → Branch: main, Ordner: /) ist sie direkt als Webseite erreichbar.

Der Prototyp speichert seinen Zustand nur lokal im Browser (`localStorage`) — noch keine geteilte Datenbank zwischen Geräten.
